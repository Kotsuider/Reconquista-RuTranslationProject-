# Проект перевода Reconquista на русский язык

## Общие сведения
Перевод делается gemini с последующей редактурой.
Этот перевод расчитан под шрифт `Gadugi` и `Noto Serif JP` для GUI

## Установка
1. Скачайте.
2. Распакуйте архив в папку с заменой файлов (предварительно сделав копию оригинального `scenario.arc`).
3. Запустите `patch_menu.exe` (или `patch_menu.bat`), чтобы перевести верхнюю строку системного меню окна на русский язык.
4. Установите `NotoSerifJP-VariableFont_wght.ttf`, если семейство `Noto Serif JP` ещё не установлено, и запустите игру.
5. Выставите шрифт `Gadugi` в настройках.
6. Профит!


# Инструкция по сборке перевода Reconquista

Данное руководство описывает полный цикл: от выгрузки таблицы перевода до упаковки готового архива `scenario.arc`.

---

## Подготовка инструментов

Перед началом работы убедитесь, что у вас установлены и скачаны:
1. **GARbro** — для распаковки и упаковки игровых архивов `.arc`.
2. **Python 3.10+** с установленной библиотекой `openpyxl`:
   ```bash
   pip install openpyxl
   ```
3. Папка инструментария [MajiroTool](https://github.com/AtomCrafty/MajiroTools) 

---

## 0. Получение актуального перевода

1. Положите Markdown-таблицы в папку `Reqonquista` рядом с `MajiroTool.Cli.v1.0.26.1156/build_translation.bat`.
2. Скопируйте содержимое `ToMajiTools` в `MajiroTool.Cli.v1.0.26.1156`.

---

## 1. Распаковка оригинального архива (GARbro)

1. Запустите **GARbro**.
2. Откройте оригинальный архив **`scenario.arc`** из каталога.
3. Распакуйте все файлы из архива в папку:
   ```text
   MajiroTool.Cli.v1.0.26.1156\st\
   ```
   *(В папке `st` должны оказаться оригинальные файлы `.mjo` и `.csv`).*
4. Запустите батник:
   ```text
   MajiroTool.Cli.v1.0.26.1156\disassemble_st.bat
   ```
   Он автоматически разберёт все `.mjo` файлы на чистые `.mjil` (код) и `.mjres` (текстовые ресурсы).

---

## 2. Структура файлов перед сборкой

Убедитесь, что файлы расположены следующим образом:

```text
(папка новелллы)/
├── scenario/                      <-- Исходная папка сценария (содержит .csv)
└── MajiroTool.Cli.v1.0.26.1156/   <-- Папка инструментария
    ├── Reqonquista/               <-- Markdown-таблицы перевода
    ├── st/                        <-- Чистые оригиналы из архива (.mjo, .mjil, .mjres, .csv)
    ├── config.mjo                 <-- Скомпилированный рабочий конфиг шрифтов
    ├── mjres_tool.py              <-- Скрипт переноса строк из Markdown в .mjres
    ├── wrap_mjres.py              <-- Скрипт безопасного автопереноса строк (с отступом \u3000)
    ├── sanitize_mjres.py          <-- Скрипт замены несовместимых символов CP932 («», —, – и др.)
    ├── patch_menu.exe             <-- Автономная утилита на Rust для локализации меню .exe (без Python)
    ├── menu_translation.json     <-- Словарь перевода системного меню окна
    ├── patch_menu.bat             <-- Батник запуска перевода меню в .exe
    ├── disassemble_st.bat         <-- Батник разового дизассемблирования чистых файлов
    ├── build_translation.bat      <-- Главный батник сборки
    └── scenario_tl/               <-- Сюда автоматически запишется результат сборки
```

---

## 3. Сборка перевода в один клик

1. Перейдите в папку `MajiroTool.Cli.v1.0.26.1156`.
2. Запустите:
   ```text
   build_translation.bat
   ```

### Что батник делает автоматически:
1. **Восстановление чистоты:** копирует чистые оригинальные `.mjil` и `.mjres` из `st/` в рабочую папку `scenario/` (перевод всегда накладывается на чистые исходники).
2. **Вставка перевода:** переносит свежий русский текст из Markdown-таблиц в `Reqonquista/` в `.mjres`.
3. **Автоперенос строк:** аккуратно делит длинные строки по границам слов (пробелам) с сохранением японского отступа `\u3000`, исключая обрезку слов движком.
4. **Санитизация:** заменяет типографские кавычки-ёлочки, длинные тире и спецсимволы на совместимые аналоги, предотвращая ошибки компилятора CP932.
5. **Компиляция:** собирает все 181 файл через `maji assemble`.
6. **Экспорт:** копирует готовые `.mjo`, рабочий `config.mjo` и системные `.csv` файлы в папку **`scenario_tl`**.

---

## 4. Упаковка архива в игру (GARbro)

1. Откройте **GARbro**.
2. Зайдите в папку:
   ```text
   MajiroTool.Cli.v1.0.26.1156\scenario_tl\
   ```
3. Выделите **все файлы внутри `scenario_tl`** (`Ctrl + A`).
4. В верхнем меню выберите: **File → Create Archive...**
5. Настройки архива:
   - **Archive type:** `Majiro (ARC)`.
   - **Target name:** `scenario.arc`.
6. Сохраните новый `scenario.arc` в папку (предварительно сделав резервную копию старого архива).

---

## 5. Локализация системного меню окна (.exe)

Верхнее меню окна (`Файл`, `Экран`, `Авточтение`, `Пропуск`, `Настройки` и др.) вшито непосредственно в исполняемый файл. Чтобы перевести его без необходимости распространять модифицированный `.exe`:
1. Запустите:
   ```cmd
   patch_menu.exe
   ```
   *(Утилита полностью автономна, написана на Rust и не требует Python или каких-либо установленных библиотек).*
2. Программа автоматически создаст резервную копию `レコンキスタ.exe.bak` и мгновенно пропатчит меню в `レコンキスタ.exe`.
